What does your photo reveal?

Photos carry hidden data: where they were taken, when, which phone, who is in them, sometimes an uncropped preview or a hidden video. Drop one in to see it, choose what to remove, and download a clean copy.

  • ✓ Runs on your device
  • ✓ Nothing is uploaded
  • ✓ Open source · npm

This browser cannot show this format (HEIC needs Safari). Reading and removing metadata still works.

Optional. Finds faces and revealing objects on your device.

·

# how it works

  1. Read. The page reads the metadata blocks inside the file: EXIF, XMP, IPTC, PNG text, HEIC items, and anything stored after the picture.
  2. Choose. Each finding is grouped by what it gives away. Tick what you want gone. Faces are optional and found on your device.
  3. Clean. Metadata is cut out without re-compressing the picture, so quality is untouched. Only hiding faces re-encodes the image.

# proof that nothing leaves your device

  • Your browser enforces it. This page is served with a Content-Security-Policy that only allows connections back to this site, which has nowhere to receive uploads. Check the response headers in your browser's developer tools: 
    • 
          
  • Watch the network. Open the Network tab, then add a photo. Nothing is sent. The only requests are this site's own files: the place-name list and, if you ask for a scan, the face and object detectors.
    • 
          
  • Go offline. Once the page has loaded, switch to airplane mode. Reading and cleaning photos still works.
    • 
          
  • Read the code. Everything is open source under the MIT licence: github.com/sivaguru94/safe-upload. The same engine is published on npm as safe-upload.

# for developers

        
Clean photos in your own upload form before they leave the user's device. Zero-dependency core, works in browsers, workers, Node, Deno and Bun.

        
npm install safe-upload

import { inspect, strip } from 'safe-upload';

const report = await inspect(file);   // what the photo reveals
const clean  = await strip(file);     // lossless: GPS, serials, names… removed
await fetch('/upload', { method: 'POST', body: new Blob([clean.bytes], { type: clean.mime }) });
